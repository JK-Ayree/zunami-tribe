# F9 — Dashboard API Contract

## 1. Назначение

API предоставляет данные для дашборда мониторинга:

- общую статистику по хостам;
- список хостов с последними показателями;
- историю метрик выбранного хоста за последний час.

F9 использует данные, поступающие через F6.

## 2. Общая сводка

`GET /api/dashboard/summary`

Успешный ответ: HTTP `200 OK`

```json
{
  "total_hosts": 4,
  "online_hosts": 3,
  "offline_hosts": 1
}
```

Поля:

| Поле | Тип | Описание |
|---|---|---|
| `total_hosts` | integer | Общее количество зарегистрированных хостов |
| `online_hosts` | integer | Количество хостов со статусом `online` |
| `offline_hosts` | integer | Количество хостов со статусом `offline` |

Хосты со статусом `unknown` учитываются в `total_hosts`, но не входят в `online_hosts` и `offline_hosts`.

## 3. Список хостов

Для получения списка используется существующий endpoint F2:

`GET /api/hosts`

Успешный ответ: HTTP `200 OK`

```json
{
  "items": [
    {
      "id": 1,
      "name": "lab-server-01",
      "status": "online",
      "last_seen_at": "2026-11-27T15:00:05Z",
      "last_metrics": {
        "cpu_percent": 23.5,
        "ram_percent": 61.0,
        "disk_percent": 44.2
      }
    }
  ],
  "total": 1
}
```

`last_metrics` содержит последние полученные показатели.

Если метрик ещё нет:

```json
"last_metrics": null
```

F9 не должен создавать отдельный endpoint для получения списка хостов.

## 4. История метрик выбранного хоста

`GET /api/hosts/{id}/metrics?minutes=60`

Назначение: получить историю показателей выбранного хоста за последний час.

Параметры:

| Параметр | Тип | Описание |
|---|---|---|
| `id` | integer | ID хоста |
| `minutes` | integer | Период в минутах. Для первой версии используется значение `60` |

Успешный ответ: HTTP `200 OK`

```json
{
  "host_id": 1,
  "items": [
    {
      "collected_at": "2026-11-27T14:59:00Z",
      "cpu_percent": 23.5,
      "ram_percent": 61.0,
      "disk_percent": 44.2
    },
    {
      "collected_at": "2026-11-27T15:00:00Z",
      "cpu_percent": 25.0,
      "ram_percent": 62.0,
      "disk_percent": 44.5
    }
  ]
}
```

Требования:

- Возвращать данные только указанного хоста.
- Учитывать последние 60 минут.
- Группировать данные по минутам и возвращать средние значения за каждую минуту.
- Возвращать не более 60 точек.
- Сортировать точки по времени от старых к новым.

Если данных нет:

```json
{
  "host_id": 1,
  "items": []
}
```

## 5. Ошибки

### Хост не найден

HTTP `404 Not Found`

```json
{
  "error": {
    "code": "not_found",
    "message": "Host not found"
  }
}
```

### Некорректный параметр периода

HTTP `400 Bad Request`

```json
{
  "error": {
    "code": "validation_error",
    "message": "Invalid minutes parameter"
  }
}
```

Все ошибки возвращаются в общем формате проекта.

## 6. Источники данных

- Таблица `hosts` — информация о компьютерах и их статусах.
- Таблица `metrics` — полученные технические показатели.

Новые таблицы для F9 не требуются.

## 7. Границы первой версии

В F9 не входят:

- произвольный выбор периода;
- сравнение нескольких хостов;
- экспорт отчётов;
- аналитика за дни и недели;
- автоматическое обновление в реальном времени;
- уведомления и история алертов.

F9 отвечает за отображение уже имеющихся данных, а не за сбор метрик или изменение статусов хостов.
